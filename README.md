# 💳 Smart Payment Retry Agent

**Razorpay AI Builder Internship 2026 — Track 3: AI Revenue Recovery**

## Problem

When a payment fails, most systems retry blindly — same time, same method,
no context. This wastes recovery attempts and leaves revenue on the table.
A card that's simply expired will never succeed on retry, while a UPI
timeout will often succeed within minutes. Treating every failure the same
way costs merchants real money.

## Solution

**Smart Payment Retry Agent** analyzes each failed transaction's reason
code and context, then recommends:

1. **When** to retry (immediately, in 30 minutes, in 24-48 hours, or never)
2. **How** to retry (same method, alternate method, or require customer action)
3. **Why** — a plain-language explanation for the recommendation
4. **Recovery likelihood** — High / Medium / Low, to help prioritize follow-up

This turns blind retries into a targeted recovery strategy, improving
payment success rates without manual review of every failure.

## How it works

- A dataset of failed transactions (`sample_transactions.csv`) simulates
  real payment failure logs (insufficient funds, expired cards, bank
  timeouts, suspected fraud, etc.)
- Each transaction is passed to **Claude (Anthropic API)** with a prompt
  that asks it to classify the failure and recommend a retry strategy
- If no API key is provided, a **rule-based fallback engine** (built from
  common payments-industry retry heuristics) still produces a full
  recommendation — so the app always works, live-API or not
- Results are shown in a **Streamlit dashboard** with summary metrics,
  charts, and a per-transaction recommendation panel

## Tech stack

- **Frontend/App**: Streamlit
- **AI**: Anthropic Claude API (`claude-sonnet-4-6`)
- **Data**: Pandas + a mock CSV dataset
- **Charts**: Plotly

## Running it locally

```bash
git clone <your-repo-url>
cd smart-retry-agent
pip install -r requirements.txt

# optional — enables live AI calls; without it, the app uses the
# rule-based fallback engine automatically
export ANTHROPIC_API_KEY="your-key-here"

streamlit run app.py
```

The app opens at `http://localhost:8501`. Select any transaction and click
**Generate Recommendation**.

## Deploying for the demo video (free, ~2 minutes)

1. Push this folder to a GitHub repo
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub
3. Click "New app", pick the repo, set main file to `app.py`
4. (Optional) Add `ANTHROPIC_API_KEY` under app Secrets
5. Deploy — you'll get a public URL to demo and screen-record
